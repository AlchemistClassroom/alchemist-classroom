# The Alchemist Classroom — website

Source for alchemistclassroom.com (GitHub Pages).

- **Add an app or section:** edit `catalog.js` only.
- **Art:** put images in `images/` using the file names in `catalog.js`.
- **Buy buttons:** paste each app's checkout link into its `buyUrl` in `catalog.js`.
- Never put a paid app's files in this repository. It's public.
